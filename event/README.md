# 풀무원 컨퍼런스 럭키드로우 & 실시간 퀴즈

두식이와 함께하는 행사 운영 시스템입니다. 운영자 한 명이 PC 한 대로 참석자 체크인, 럭키드로우, 실시간 퀴즈, 수상자 발표까지 진행할 수 있습니다.

- 외부 패키지 없이 **Node.js 18 이상**만 있으면 실행됩니다.
- 실시간 전달은 SSE로 하고, 데이터는 `data/db.json`에 저장합니다.
- 추첨, 채점, 풀이 시간 측정은 모두 서버에서 합니다. 정답은 참가자 브라우저로 전달하지 않습니다.

## 실행

```bash
cd event
# 행사 전 반드시 비밀번호 설정
set ADMIN_PASSWORD=최고관리자비밀번호      # PowerShell: $env:ADMIN_PASSWORD="..."
set OPERATOR_PASSWORD=운영자비밀번호
npm start                                  # 또는 node server.js  (기본 포트 3000, PORT 로 변경)
```

| 화면 | 주소 | 용도 |
|---|---|---|
| 운영자 콘솔 | `/admin` | 최고 관리자와 행사 운영자가 각자의 비밀번호로 로그인 |
| 행사장 스크린 | `/screen?key=…` | 콘솔의 "행사장 스크린 열기"로 키가 포함된 주소 열기. 키오스크로 쓸 때는 `&autostart=1` 추가 |
| 체크인 (모바일) | `/checkin` | 스크린 홈 화면의 QR |
| 퀴즈 (모바일) | `/quiz` | 스크린 퀴즈 화면의 QR |

**참석자 휴대폰에서 접속하려면** 서버 PC와 같은 와이파이에서 `http://PC-IP:3000`으로 접속하게 하거나 공개 서버에 배포합니다. 서버를 실행하면 콘솔에 접속 주소가 출력됩니다. 콘솔의 **설정 → 참석자용 공개 주소**에 그 주소를 넣으면 QR에 반영됩니다.

> Vercel 같은 서버리스 정적 호스팅에서는 동작하지 않습니다. 실시간 연결을 계속 유지하고 상태를 저장해야 하기 때문입니다.
> 사내 PC나 서버, 또는 Render·Railway·Fly.io·클라우드 VM처럼 Node 프로세스가 계속 떠 있는 곳에 배포하세요.
> 배포할 때 `DATA_DIR`을 영구 디스크 경로로 지정하고, 반드시 HTTPS를 사용하세요.

## 행사 당일 순서

1. **참석자 명단:** Google Forms 응답 시트를 "링크가 있는 모든 사용자: 뷰어"로 공유합니다. 콘솔 **참석자** 탭에 시트 주소를 넣고 동기화합니다. CSV 파일을 업로드해도 됩니다.
   - 이름, 회사/소속, 휴대전화/이메일, 동의 열을 자동으로 인식합니다.
   - 중복 응답, 연락처 충돌, 미동의, 필수값 누락은 "검토 필요" 목록으로 따로 모입니다.
2. **현장 인증 코드(권장):** **설정**에서 코드를 지정하면 행사장 스크린에만 표시됩니다. 행사장에 실제로 온 사람만 체크인할 수 있게 하는 장치입니다.
3. **체크인:** 스크린 홈 화면의 QR로 체크인합니다. 체크인을 마친 사람만 추첨 대상이 됩니다.
4. **럭키드로우:** 등수별로 상품, 이미지, 인원, 방식(1명씩 또는 일괄)을 설정한 뒤 추첨합니다. 등수는 원하는 순서로 추첨할 수 있습니다.
   - 한 번 당첨된 사람은 이후 모든 추첨에서 자동으로 제외됩니다.
   - 당첨 무효 처리는 최고 관리자만 할 수 있고, 사유를 반드시 기록해야 합니다.
5. **퀴즈:** 문제와 수상 인원 N을 저장합니다. 이후 **대기실 열기 → 퀴즈 시작 → 마감(제한 시간이 끝나면 자동) → 결과 발표** 순서로 진행합니다.
   - 순위는 정답 수가 많은 순, 같으면 풀이 시간이 짧은 순입니다. 수상자는 만점자 중 빠른 순서로 N명입니다.
   - 풀이 시간은 서버 기준 퀴즈 시작 시각부터 마지막 답안을 받은 시각까지입니다(서버 단조 시계, ms 단위).
6. **결과 내보내기:** 참석자, 추첨, 퀴즈, 감사 로그를 각각 CSV로 내려받을 수 있습니다. 엑셀에서 한글이 깨지지 않도록 BOM을 포함합니다.
7. **리허설 후 정리:** 리허설이 끝나면 **설정 → 데이터 초기화**로 테스트 기록을 지웁니다.

## 두식이 캐릭터 이미지

`public/assets/dusik.svg`는 임시 일러스트입니다. 공식 캐릭터 이미지를 `public/assets/dusik.png`(또는 `.webp`)로 넣으면 모든 화면에 자동으로 적용됩니다. 정사각형에 투명 배경인 이미지를 권장합니다.

## 사운드

배경음악과 효과음은 브라우저에서 직접 합성한 오리지널 음원이라 음원 라이선스가 필요 없습니다. 휴대폰 브라우저는 자동 재생을 막기 때문에, 참가자 화면에서는 **사운드 켜기** 버튼을 눌러야 소리가 납니다. 음악은 행사장 스크린 PC에서 재생하는 것을 기준으로 만들었습니다.
